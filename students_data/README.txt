Student data is loaded from both the database (igangaschool_students.students) and
Excel files in this directory. The student-directory.php page shows ALL students merged
and allows you to:

- Search by name, index number, NSIN, phone, program, level, set, gender
- View profiles with full details including mobile numbers
- Add new students (saved to database)
- Edit student records (Excel-sourced students are saved to database on edit)
- Delete student records (database only)

Each student card shows whether the data is from the database ("DB" badge)
or from an Excel file ("Excel" badge).
